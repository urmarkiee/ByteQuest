# ByteQuest — Reference UI implementation map

| Screen from image | Android implementation |
|---|---|
| 1. Splash and welcome | WelcomeActivity, start button, reference hooded explorer, MR.DEV credit |
| 2. Dashboard | Home tab: avatar, student summary, continue-learning progress, 6 colored game tiles |
| 3. Play Levels | Levels tab: topic-colored numbered cards, lock/unlock state, replay |
| 4. Quiz topics | Quiz tab: 7 subject rows, total and attempted counts, 50-question and 10-question sets |
| 5. Quiz question | Four glowing option cards, progress, correctness feedback, reference |
| 6. Lesson | Lessons tab: topic visual, explanation, key ideas, example, practice |
| 7. Achievements | More → Achievements: three-column badge grid and badge detail dialogs |
| 8. Reports | More → Reports: overview, 7 topic progress bars, recent activity |
| 9. Classroom | More → Classroom: code generation/join, offline challenges |
| 10. Profile and settings | More → Profile and More → Settings, MR.DEV branding |
| 11. Bottom navigation | Icon and label bar with active highlight |
| 12. Theme variations | Dark neon theme implemented; other themes are NOT included in this edition |

This faithfully adapts the **design direction and information hierarchy** from the image, not its non-editable illustration pixels or every exact graphic effect. This is a functional native Android project and source, not an APK.
