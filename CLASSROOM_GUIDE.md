# ByteQuest Classroom Challenge Guide

1. On a teacher device, open **Class → Create a classroom code**.
2. Choose All Topics, a specific topic, and the number of puzzles.
3. Press **Generate code**. Example: `BQ4-LOG-3` covers three logic-gate puzzles. The new `BQ4-ALL-12` covers the entire campaign.
4. Share or copy the code to learners. Every device includes the same built-in puzzle bank and does **not** contact a server.
5. Students open **Class → Join**, enter the code, and complete the challenge.
6. Students use **Share results** to send a text result to the teacher.

**Scoring:** 10 points per correctly solved puzzle on the first submitted attempt, without hints; otherwise 5 points when solved. Wrong checks and hints are recorded locally.

**Important:** This is offline guided practice, not a secure exam or a synchronized classroom management service. Anyone with the app can generate a code. Results are self-reported, and identical codes always select the same fixed puzzles. Avoid using it for high-stakes grading.

## New 350-question version

Select the Class tab and create a **BQQ** quiz code: choose any of the seven topics for a 50-question challenge, or All Topics for the full 350. The code `BQQ-ALL-350` covers every question. A smaller `BQQ-NUM-10` chooses the first 10 number-system questions. The original `BQQ-ALL-50` still chooses the original 50-question bank, not 50 newly reordered items. Teacher result verification is manual; codes and scores are not server-authenticated.
